# 유스케이스 — HobbyFind

## 액터
비회원, 회원, 시스템(NextAuth/Supabase)

## 시나리오
1. 비회원이 홈에서 카드를 둘러본다.
2. 카테고리 메뉴로 전용 페이지에 들어간다.
3. 북마크를 누르면 로그인으로 보낸다.
4. 회원가입(약관 동의, 비밀번호 확인) 후 세션이 생긴다.
5. 잘못된 비밀번호는 에러 메시지를 보여 준다.
6. 회원이 북마크하면 Supabase `bookmarks`에 저장되고 화면에 즉시 반영된다.
7. 마이페이지에서 카테고리별 개수 막대와 목록을 본다.

## 예외
환경변수 없음, DB 오류 시 API가 안내 문구를 반환한다.
