# PRD — HobbyFind

## 1. 제품 상세 설명
HobbyFind는 운동형·지능형·예술형 세 카테고리로 취미를 탐색하고, 회원은 북마크와 마이페이지 통계를 쓰는 웹서비스다.

## 2. 참고 서비스
Airbnb 카드 UI, 심플한 탐색 그리드.

## 3. 핵심 기능
- 비회원: 홈/카테고리 탐색
- 회원: 북마크 추가·해제, 마이페이지 통계
- 인증: NextAuth Credentials + Google + 카카오, 데이터는 Supabase

## 4. 페르소나
취미를 찾고 싶은 20–30대. 주말에 해볼 활동을 고르고 저장한다.

## 5. 기술 스택
Next.js, Tailwind, NextAuth, Supabase

## 6. 제한사항
취미 목록은 강의 가이드 고정 18종. 추가 기능 제안 없음.

## 7. 제안 추가 기능
소셜 로그인: Google, 카카오.

## 취미 리스트 (고정)
- 운동형: 조깅/러닝, 요가, 수영, 자전거, 클라이밍, 댄스
- 지능형: 독서, 퍼즐, 체스, 프로그래밍, 외국어 학습, 사진 촬영
- 예술형: 그림 그리기, 악기 연주, 요리, 서예, 도자기 만들기, 정원 가꾸기
