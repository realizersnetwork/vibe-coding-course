# 유스케이스 — HobbyFind

## 1. 액터
비회원, 회원, 시스템(NextAuth / Supabase)

## 2. 시나리오
1. 비회원이 홈에서 카드를 둘러본다.
2. 검색하거나 카테고리 페이지로 들어간다.
3. 북마크를 누르면 로그인으로 보낸다.
4. 이메일 가입(약관 동의, 비밀번호 확인) 또는 Google/카카오로 세션이 생긴다.
5. 잘못된 비밀번호는 에러 메시지를 보여 준다.
6. 북마크는 Supabase `bookmarks`에 저장되고 화면에 바로 반영된다.
7. 마이페이지에서 카테고리별 개수 막대와 목록을 본다.

## 3. 대체 흐름
이미 가입된 이메일, 약관 미동의, 소셜 로그인 취소, DB 오류.

## 4. 사전/사후
- 사전: 환경변수와 테이블이 준비되어 있다.
- 사후: JWT 세션, 북마크 행이 추가되거나 삭제된다.

## 5. 제약
취미 18종 고정. 상세 페이지 없음.

## 6. 예외
API가 실패 문구를 반환하고 화면이 안내한다.

## 7. 보안
비밀번호는 bcrypt, 서버는 service_role만 DB에 접근한다.
