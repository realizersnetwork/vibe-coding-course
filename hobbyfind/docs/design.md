# 디자인 가이드 — HobbyFind (Airbnb 톤)

## 1. 시스템
흰 배경, 넓은 여백, 둥근 카드, 포인트 `#FF385C`. hover 시 카드가 살짝 떠 오른다.

## 2. Tailwind 색
- Primary `#FF385C`
- 배경 `#F7F7F7` / `#FFFFFF`
- 텍스트 `#222222` / `#737373`
- 테두리 `#E5E5E5`
- 카카오 버튼 `#FEE500`

## 3. 페이지
- 홈: sticky Top Bar, Hero fade-in, 검색·필터, 3열 그리드
- 카테고리: 제목 + 소개 + 해당 카드만
- 로그인/가입: 중앙 카드, 이메일·비밀번호, Google·카카오
- 마이페이지: 카테고리 막대 차트 + 북마크 그리드

## 4. 레이아웃
max-w-6xl, 카드 `sm:grid-cols-2 lg:grid-cols-3`

## 5. 인터랙션
버튼 hover, 북마크 즉시 반영, 비회원 북마크는 `/login`

## 6. 반응형
모바일에서 카테고리 메뉴는 숨기고 로고·인증만 남긴다.
