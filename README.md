## 프로젝트 개요

HobbyFind는 운동형, 지능형, 예술형 세 카테고리로 취미를 둘러보고, 관심 있는 항목을 북마크해 마이페이지에서 통계로 확인하는 서비스입니다.

비회원은 탐색·검색만 할 수 있고, 회원은 이메일·Google·카카오 로그인 뒤 북마크와 마이페이지를 씁니다.

## 기술 스택

### Frontend

Next.js, React, TypeScript, Tailwind CSS, Framer Motion

### Backend & Database

Supabase, NextAuth.js, bcryptjs

### Auth

이메일/비밀번호, Google, 카카오

git clone https://github.com/realizersnetwork/vibe-coding-course.git
